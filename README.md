# Titration Lab

Acid–alkali titration simulator for Combined Science and Pure Chemistry (Science is Khool).

- **Pre-Lab**: name the apparatus → set up and titrate (rough + accurate, until concordant) → titration table → calculations (own HCl data + partner's H2SO4 data) → Pure Chem only: choosing indicators from pH curves. Earns an on-device badge.
- **Challenge** (unlocks with the badge): a mystery NaOH sample with HCl or H2SO4, timed and scored out of 1200 (Combined) / 1300 (Pure).
- Results go to the Google Sheet tab **Titration** (`SUBMIT_URL` / `SHEET_TAB` at the top of the script).
- Challenge music: `challenge.mp3` (Retro Game Loop) in this folder.
